# 我要应助功能技术文档

## 接口

- `POST /api/lit-request/assist`
- 请求类型：`multipart/form-data`
- 请求参数：`litRequestId`、`file`
- 请求头：`Authorization: Bearer <token>`

## 后端设计

- `LitRequestController` 接收 multipart 请求并提取 token。
- `LitRequestService` 校验用户、文献求助、文件名后缀和 PDF 内容。
- `MinioStorageService` 上传 PDF 到 `paperhub-literature` bucket。
- `LitAssistMapper` 写入 `literature_assist` 应助记录。

## 存储设计

- MinIO 配置位于 `application.yml` 的 `paperhub.minio`。
- 对象路径格式：`assist/yyyy/MM/{litRequestId}/{userId}-{uuid}.pdf`。
- 数据库只保存 MinIO 对象名，不保存文件二进制内容。
