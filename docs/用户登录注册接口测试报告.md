## 5. 关键测试记录

### 5.1 图形验证码 Redis 写入

接口：

```text
GET http://localhost:18080/api/auth/captcha
```

验证点：

```text
Redis Key: auth:captcha:{captchaId}
TTL: 299
```

结论：

```text
图形验证码已从内存存储迁移到 Redis，并具备过期时间。
```

### 5.2 注册接口

测试方式：

1. 手动向 Redis 写入邮箱验证码。
2. 调用注册接口。
3. 查询数据库用户表。
4. 查询 Redis 邮箱验证码 Key。

测试 Redis Key：

```text
auth:email-code:register:{email}
```

结论：

```text
注册成功后用户正常入库，邮箱验证码 Key 被删除。
```

### 5.3 登录接口

测试覆盖：

- 缺少图形验证码。
- 图形验证码错误。
- 密码错误。
- 密码正确。

验证点：

```text
auth:login:fail:{email}
auth:captcha:{captchaId}
```

结论：

```text
登录接口已强制校验图形验证码；密码错误会累计登录失败次数；登录成功后会清除失败次数并删除图形验证码。
```

## 8. 测试结论

本次接口测试通过。

已验证能力：

- 图形验证码写入 Redis。
- 图形验证码具备 TTL。
- 图形验证码错误次数累计。
- 注册接口可以校验 Redis 邮箱验证码。
- 注册成功后删除邮箱验证码。
- 登录接口必须输入图形验证码。
- 登录密码错误会累计失败次数。
- 登录成功后清除失败次数。
- 登录成功后删除图形验证码。
